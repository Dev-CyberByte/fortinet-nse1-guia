# NSE 1 — Cybersecurity and Cloud Fundamentals (guía de estudio en español)

Guía de repaso por módulos del curso **Fortinet NSE 1 – Cybersecurity and Cloud Fundamentals**, para reforzar los conceptos base antes de **NSE 2** y **NSE 3**.

> ℹ️ **Sobre el contenido:** está armada con la estructura oficial del curso (10 módulos y sus lecciones) y los conceptos estándar de cada tema. Los términos clave van en **inglés entre paréntesis** porque el curso y el examen están en inglés. Repasa siempre con las lecciones oficiales: Fortinet actualiza el curso y puede cambiar el énfasis de algunos temas.

## Datos del curso y la certificación

| | |
|---|---|
| Duración estimada | ~11 horas |
| Estructura | 10 módulos, con lecciones interactivas |
| Evaluación | Un quiz al final de cada módulo |
| Aprobación | **80 % o más** en cada quiz |
| Resultado | Badge y certificación **NSE 1 in Cybersecurity** |
| Vigencia | 2 años desde que completas el curso |
| Renovación | Repetir el curso o renovar/lograr cualquier certificación NSE 1–7 extiende la vigencia |

## Cómo estudiar
1. Ve la lección oficial → lee el resumen del módulo aquí → contesta la **autoevaluación**.
2. Haz primero las **tablas comparativas**: el quiz suele pedir distinguir conceptos parecidos (virus vs worm, SIEM vs XDR, DAC vs MAC...).
3. Memoriza las **listas ordenadas** (Kill Chain, factores de autenticación, modelos de nube).
4. Repite el quiz de práctica hasta pasar de 80 % con holgura.
